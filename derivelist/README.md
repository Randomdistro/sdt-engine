## Provenance note on c (recorded 2026-07-30)

The Mercury-precession closure (`GOM04`, tallied as B27) reconstructs
c = k_Sun·v_surface to +0.0009%. It is **withdrawn as a derivation of c**: the
ephemeris orbital elements it consumes (eccentricity, precession rate) are produced
by fits that model light propagation with c, so c enters upstream of the closure.
The spectroscopic route stands as primary: one hydrogen ladder measured as
frequency and as wavenumber returns the one relay speed. The closure is retained
as a cross-domain consistency check.
