# Fission-fragment Z per mass number — Wahl evaluated tables (U-235 thermal)

Retrieved 2026-10-05. Source: A. C. Wahl, *Atomic Data and Nuclear Data Tables* 39, 1 (1988); IAEA-TECDOC-1168 appendices at
`http://nds.iaea.org/public/download-endf/zv_VMS_Archive/WAHL/APP-A1.TXT` (U235T, U238F, U238H, Pu239T; independent fractional yields FI per Z for each A; `*` marks values from experiment, unmarked values are Zp-model estimates). Yields are for fragments **after prompt-neutron emission**.

`raw/exa_APP-A1_first140k.txt` is the first 140,000 characters of that file as returned by a text-extraction service (direct curl returned a Cloudflare challenge page). It covers U235T in full for A = 60–175. It is an extraction, not a byte copy of the IAEA file; sha256 in the run log. `raw/challenge_pages_not_data/` holds the two challenge pages that curl returned, kept only so they are not mistaken for data.
Not available from this source: U-233(n_th,f) and Cf-252(sf) (Wahl's APP-A1 does not include them; Cf-252 fractional yields appear in `UKFY2/UKFY2_6` on the same server, not yet fetched).
