# PREM reference Earth model (tabulated)
`PREM_TauP_prem.nd` — the Preliminary Reference Earth Model (Dziewonski and Anderson 1981, Phys. Earth Planet. Inter. 25, 297) as distributed with TauP and ObsPy: columns depth (km), P velocity (km/s), S velocity (km/s), density (g/cm³), Q_P, Q_S; named discontinuities as labels. Retrieved 2026-10-05 with curl from `raw.githubusercontent.com/crotwell/TauP/main/src/main/resources/edu/sc/seis/TauP/StdModels/prem.nd`; the ObsPy copy (`obspy/taup/data/prem.nd`) is byte-identical in size (5,397 bytes). This is a tabulation of the published model, not the original paper's polynomial coefficients; IRIS EMC (`ds.iris.edu`) refused direct download. Used by `Investigations/06_Gravitation_and_Orbital_Mechanics/GOM09_Earth_Core_Seismic_Speed` as the comparison profile only; density and velocity are comparison columns and are not inputs to any SDT chain (mass enters SDT only as baryon count and spatial resistance).
