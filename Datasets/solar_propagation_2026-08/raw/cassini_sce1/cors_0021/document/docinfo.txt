      The DOCUMENT directory contains documentation on the archival data
set and files within the data set.

     The files are:

DOCINFO.TXT

     A brief description of the files within the DOCUMENT directory
(this file).


CASRSSIS.TXT

      SIS  for the Cassini Radio Science Raw Data Archive.


CK_MM_SIS_000614.TXT

     SIS for C-Kernel files (CKF).


DORS_002_020501.TXT

     SIS for Path Delay files  from AWVR 1 and AWVR 2.


SPK_MM_SIS_000525.TXT

     SIS for Spacecraft and Planetary Ephemerides (SPK) files.


TRK_2_21_950831.TXT

     SIS for Earth Orientation Parameters (EOP) files.


TRK_2_23_000531.TXT

     SIS for Ionosphere Calibration files (ION)
and Troposphere Calibration files (TRO).


ROL_021101.TXT

    Description of the contents of the RSR Operations Log (ROL) files.


RSRLOG_021101.TXT

   Description of the contents of the RSR Validation Log files.
