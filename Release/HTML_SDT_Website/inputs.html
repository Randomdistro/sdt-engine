The radiative boundary

Solid colour red ends at 750 nm; infrared begins. That is the emission of this cycle. N = 1.063 mm / 750 nm = 1418. Temperature falls by the same factor: 3864 K → 2.7255 K. The universe’s life is that wall. Matter did not set it.
