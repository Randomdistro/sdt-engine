# Horizons Kinematics Demonstration Protocol

Status: pre-registered before the rebuilt instrument is run.

## Scope

This package demonstrates a kinematic length parameter,

`koppa = mu / c^2`,

using NASA/JPL Horizons geometric Cartesian state vectors. It parses a Horizons
vector table, estimates the central radial acceleration from the velocity
history, expresses the resulting gravitational parameter as koppa, and performs
a deterministic two-body propagation from the first supplied state.

The demonstration is not a replacement for JPL DE ephemerides, SPICE, orbit
determination, covariance propagation, relativistic corrections, or mission
navigation. The koppa form is an algebraic reparameterisation of the usual
central gravitational parameter; agreement with Horizons is a consistency test,
not independent evidence for a force law.

## Inputs

- Unedited Horizons vector-table text or CSV containing `$$SOE` / `$$EOE`.
- Required columns: JDTDB, calendar label, X, Y, Z, VX, VY, VZ.
- Required units for this instrument: `KM-S`.
- The first state is the propagation initial condition.
- No mass, G, or fitted trajectory correction enters the demonstration.

The bundled example is the existing repository fixture
`jpl_horizons_earth_heliocentric_2002_157_160.csv`, generated by Horizons from
DE441 for Earth (399), centred on the Sun (10), at 15-minute cadence.

## Instrument

1. Parse the metadata and every state between `$$SOE` and `$$EOE`.
2. Convert kilometres and kilometres per second to SI.
3. Estimate acceleration at every interior row by centred differencing velocity.
4. Project acceleration radially and compute
   `koppa_i = -dot(a_i, r_i) * |r_i| / c^2`.
5. Select the median positive finite koppa as the single demonstration value.
6. Propagate the first state with velocity-Verlet under
   `a(r) = -c^2 * koppa * r / |r|^3`.
7. Compare all propagated states with the supplied Horizons states in one pass.
8. Write a row-complete CSV and a machine-readable JSON summary.

## Validation gates

- **O0 — parser:** the bundled fixture yields at least 300 rows, a positive
  cadence, `KM-S` units, Earth target metadata and Sun centre metadata.
- **O1 — synthetic known answer:** a circular synthetic orbit recovers its
  registered koppa to relative error <= `1e-8`; one period propagated with
  60-second or smaller substeps closes in position to <= `2e-6` of the radius.
- **O2 — estimator stability:** the bundled whole-range positive koppa estimates
  have robust relative median absolute deviation <= `0.002`.
- **O3 — DE441 comparison:** over the complete bundled interval, maximum
  position residual is <= `20,000 km` and maximum velocity residual is
  <= `0.05 km/s`.
- **O4 — row completeness:** the output CSV contains exactly one result row for
  every parsed Horizons state.
- **O5 — provenance:** the JSON names the source file, target, centre, source
  ephemeris, row count, cadence, estimator, integrator and every gate result.

Any failed gate is reported as `FAIL`, returns a non-zero process status, and is
retained in the run log. Thresholds are not changed after inspecting the run.
