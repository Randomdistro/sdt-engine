## P1c lock (2026-10-05, paper derivation, written BEFORE the GWTC event table was opened for values)
Ledger f(q) at contact, no G and no M: a circular two-body seat obeys v²r = c²ϟ_tot (bridge identity), so the circular binding energy is E_b = ½ μ v² = ½ μ c² ϟ_tot / r with μ = m₁m₂/(m₁+m₂). Contact is each body's surface at its own budget-symmetric point r_i = 2ϟ_i (PROMPT §1: r = 2ϟ), so the separation is r_c = 2(ϟ₁+ϟ₂) = 2ϟ_tot. The radiated fraction of the total rest energy is f = E_b/((m₁+m₂)c²) = ½ η ϟ_tot/r_c = **η/4**, with η = m₁m₂/(m₁+m₂)² = q/(1+q)² and q the mass (equivalently ϟ) ratio. At q = 1: 1/16 = 6.25%, the locked §2 value, so the §2 number follows from this derivation rather than being separately posited. **f_ledger(q) = q/(4(1+q)²).** Limitations: Newtonian circular binding "on the ledger" (no inspiral dynamics, no spin, no radiation of angular momentum), surface choice fixed here (budget points, not compression-floor surfaces; the PROMPT's P1d alternative is not run).
**Divergence from the standard account (stated before opening data):** the ledger gives f ∝ η¹; leading-order numerical-relativity fits scale as η² (and carry spin dependence). That is the shape discriminant.
**Data (registered):** GWOSC event API (`https://gwosc.org/eventapi/json/GWTC/`, fetched with curl; raw file stored under `Datasets/gw/` with sha256). Per-event medians of source-frame m₁, m₂ and final mass; f_obs = (m₁+m₂−m_f)/(m₁+m₂), q = m₁/m₂ ≥ 1. RIVAL-COMPUTED caveat (PROMPT §0.2): catalogue final masses come from NR-calibrated fits, so f_obs is NR-based, not a free measurement of the remnant.
**Gates (fixed now):** G-A (level): median f_obs of events with q < 1.5 lies within a factor 2 of f_ledger (≈ 6.0–6.25%). G-B (shape): Theil–Sen slope s of ln f_obs against ln η over all events with the three masses; bootstrap-over-events 95% interval; the ledger slope 1 inside the interval and the NR-leading slope 2 outside → discriminates for the ledger; both inside → non-discriminating; ledger outside → fails. Robustness run (registered now): the same with |χ_eff| < 0.2 where χ_eff is available. Limitation declared: bootstrap over events only (parameter-estimation uncertainty not propagated). Forbidden: dropping events after seeing the slope; changing the interval level.
