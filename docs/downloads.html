On what is not here

The Mercury-precession route to c is not offered as a paper. It reconstructs c to nine parts in a million, but the ephemeris elements it consumes come from fits that already model light propagation with c, so it is withdrawn as a derivation and kept only as a cross-domain consistency check. The input ledger records that in full.
