# SDT Experimental Programme

Falsifiable predictions derived from Spatial Displacement Theory. Each
experiment specifies the SDT prediction, the standard-model prediction, the
observable difference, feasibility, and impact. All predictions use empirically
measured values only — no interpretive frameworks imported.

**Author**: James Christopher Tyndall, Melbourne, Australia
(new specs E103+ authored as J. C. Harvey)

---

## Structure & lifecycle

- **One folder per experiment.** Each `E##` lives in `Experiments/E##_Name/`
  (currently holding its spec `.md`; room for tools/data as each is worked up).
- **E → graduation.** An experiment that is carried through a full mathematical
  investigation **graduates** to an `Investigations/` entry (topic-coded:
  `NP`, `GOM`, `CR`, `GD`, `SAR`, …). The original spec is kept as the
  falsifiable-prediction record and carries a **`⮑ GRADUATED`** banner linking
  forward to the investigation that resolved it. See the
  [Graduated](#graduated-to-investigations) table below.
- **Numbering is stable.** `E##` identifiers never change (so every reference and
  every graduation link stays valid). New experiments append at **E103+**.
