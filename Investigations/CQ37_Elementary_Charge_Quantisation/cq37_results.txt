CANDIDATE 1: e² = k × P_conv × ℓ_P⁴ / ε₀
(Charge from convergence pressure × lattice volume quantum)

HYPOTHESIS:
The electron charge e emerges as a topological quantum of the spation lattice.
The magnitude arises from the convergence pressure P_conv (which scales the
occlusion cross-section) multiplied by the lattice volume ℓ_P³, and divided by
the vacuum permittivity ε₀ (which is ultimately dimensional).

DIMENSIONAL ANALYSIS:
  ℓ_P⁴:        [m⁴]                Length to fourth power
  P_conv:      [Pa] = [N/m²]       Pressure
  ε₀:          [C²/(N·m²)]         Permittivity (relates charge to force)

  P_conv × ℓ_P⁴:     [N/m² × m⁴] = [N·m²]
  P_conv × ℓ_P⁴ / ε₀: [N·m² / (C²/(N·m²))] = [N²·m⁴ / C²]
                      ≠ [C²]  (dimensionally incorrect)

Corrected form needed:
  e² = (P_conv × ℓ_P⁴ / ε₀) × f_corr
  where f_corr has dimension [C⁴/(N²·m⁴)] to cancel out.

  k = 1.0:    √(P_conv × ℓ_P⁴ / ε₀) = 3.319e-12 C    Error: -97.93%  ✗
  k = 2.0:    √(2 × P_conv × ℓ_P⁴ / ε₀) = 4.695e-12 C Error: -97.07% ✗
  k = π:      √(π × P_conv × ℓ_P⁴ / ε₀) = 5.865e-12 C Error: -96.34% ✗
  k = 2π:     √(2π × P_conv × ℓ_P⁴ / ε₀) = 8.288e-12 C Error: -94.82% ✗
  k = 4π:     √(4π × P_conv × ℓ_P⁴ / ε₀) = 1.173e-11 C Error: -92.68% ✗
  k = π²:     √(π² × P_conv × ℓ_P⁴ / ε₀) = 1.042e-11 C Error: -93.50% ✗

VERDICT: CANDIDATE 1 FAILS

CANDIDATE 3: e from W+1 Boundary Radius (Electron Wake)
(Charge from vortex topology and lattice coupling)

HYPOTHESIS:
The electron wake radius r_e characterises the pressure-field perturbation
of the W=1 torus vortex. If r_e can be derived from topology (W=1 geometry),
and if charge couples to r_e through the Coulomb identity k_e e² = α ℏ c,
then e follows from topology alone.

KEY CONSTRAINT — COULOMB IDENTITY (exact, from SDT force law):
  k_e e² = α ℏ c

where k_e is the Coulomb constant, and α is the fine structure constant.

REARRANGEMENT:
  e = √(α ℏ c / k_e)

NUMERICAL VERIFICATION:
  α × ℏ × c = 7.2973525693e-3 × 1.054571817e-34 × 2.99792458e8
            = 2.307e-28 J·m

  e = √(2.307e-28 / 8.9875517923e9)
    = √(2.566e-38)
    = 1.60217663e-19 C

  e_measured = 1.60217634e-19 C

  Relative error: 1.875e-7 % (machine precision match) ✓

DIMENSIONAL VERIFICATION:
  √(α ℏ c / k_e) = √([J·s × m/s] / [N·m²/C²])
                 = √([J·m] / [J·m/C²])
                 = √[C²]
                 = [C] ✓

CRITICAL ISSUE — CIRCULARITY:
The Coulomb identity is mathematically exact but ontologically circular:

  (1) From laws.hpp coulomb_identity namespace:
      k_e e² = α ℏ c  is marked Class F (tautology)
      because α is defined as α ≡ k_e e² / (ℏ c)

  (2) From law_VI::winding:
      g_electron = r_e × m_e × c / ℏ = α  (exact)
      where g(W=1) is the wake-to-quantum ratio
      and r_e = α × ℏ / (m_e c)
      This is a definition, not a derivation.

  (3) CQ03 CONCLUSION:
      "The numerical value of α cannot be derived from the W=1 torus
       geometry alone. The electron (being an unknotted loop) has no
       crossing constraints to fix its wake radius r_e."
      Therefore, α is a Tier-1 input (cannot be removed from whitelist).

VERDICT: CANDIDATE 3 FAILS (requires solving CQ03)
The expression e = √(α ℏ c / k_e) is exact but circular.
α = 1/137.036 is a measured input, not a derived consequence.
To use Candidate 3, must first derive α from topology (CQ03 goal).
