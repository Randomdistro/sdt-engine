## Result — the bulge is DILUTE
For a fiducial bulge (M=10¹⁰ M_⊙, R=1 kpc):
- depth redshift **z_d = ϟ/R = 4.79×10⁻⁷ → cz = 143 m/s**.
- bulge rotation ~200 km/s → depth redshift is **0.072%** of the rotation signal.
- the branch boundary (z_d ≳ 0.1) is at **neutron-star density**; the bulge is ~6 orders below it.

## Verdict — the dense-bulge hypothesis is NOT supported, but the effect is real
The "redshift shows disk speed is false" conjecture required the bulge to be *dense* (z_d ≫ v²/c², redshift dominating the spectrum). **Computed, it is dilute:** the depth redshift is the ordinary ϟ/r, ~143 m/s, three orders below the rotation. **Disk rotation is not a redshift artifact.** (Honest miss vs the hypothesis; the pre-committed dilute branch fires.)

**But the mechanism is confirmed and quantified:** 143 m/s is a *real, zero-fit, predictable systematic*. By the symmetry fork it **cancels in the antisymmetric disk-rotation extraction** (lands in the systemic velocity) and **survives in the dispersion σ and the center-systemic offset** — the clean channels. So the correct, testable statement is:
- **A bulge center should sit ~140 m/s more redshifted than its outskirts** (the same effect the cluster shows at 14 km/s, scaled by potential).
- This is where to look — **not** in the disk rotation curve.
