# NSEQ10 Amendment 01 — polar pair vs symmetry survivors

**Date:** 2026-08-11  
**Trigger:** First instrument run showed `|C3×inversion|=2` but
`survivors ≠ {NSEQ05 triangles, NSEQ05 hexagon}`.

## Correction

NSEQ05/NSEQ08 “triangles / hexagon” are **polar-axis constructions** for the
14→42 face graph (both still valid 6-regular graphs).  
NSEQ06-independent “C3×inversion” survivors are the **axis-cycle symmetry**
cut on QQ 2-factors.

These are related but not identical label sets. NSEQ10 C2–C4 adjudicate the
**symmetry** survivors (mandatory core + binary private). Overlap with the
polar pair is reported as diagnostic, not as a fail of the selection rule.
