NP02B — GRAMMAR CHAIN GROWTH  (Investigation B)
Construction is a walk on the (n_d, n_t) lattice from He-4 at the origin.
  +deuteron : step n_d  (Z+1, A+2)
  +triton   : step n_t  (Z+1, A+3)
  paths to (n_d,n_t) = C(n_d+n_t, n_t) = C(Z-2, n_t)

========== 1. THE n_t = 0 SPINE  (pure-deuteron / alpha-conjugate ladder) ==========
Every +2 deuterons on the n_d-axis == one stellar alpha-capture (He-4 added).
This reconciles 'alpha process' with 'one alpha core + deuterons':
the captured He-4 dissolves into 2 deuterons around the single core.

  nuclide  Z  A   (n_d,n_t)   paths   stellar step
  He-4     2   4   ( 0, 0)       1   alpha core (origin)
  C -12    6  12   ( 4, 0)       1   3-alpha / C-12 ignition
  O -16    8  16   ( 6, 0)       1   C-12(a,g)O-16
  Ne-20   10  20   ( 8, 0)       1   O-16(a,g)Ne-20
  Mg-24   12  24   (10, 0)       1   Ne-20(a,g)Mg-24

  Ca-40   20  40   (18, 0)       1   Ar-36(a,g)Ca-40 (alpha process end)

  -> the spine is the single all-deuteron path (n_t=0 => 1 ordering).

========== 2. DOMINANT FAMILIAL LINKAGES  (Rule 4: parent + one block -> child) ==========
Each step is one lattice move; the block is fixed by (dZ,dA).

  reaction            block  (n_d,n_t)parent -> child
  He-4 + t -> Li-7     +t    ( 0, 0) -> ( 0, 1)

  -> +d moves along n_d, +t along n_t; a child differs from its parent
     by exactly one lattice step.  The growth graph IS the integer lattice.

========== 5. TREFOIL ROTATION & OVERLOAD  (exposed remnants and decay timing) ==========
Alpha core = W=3 trefoil; traction T = 3(W+1) = 12; w_demand = 3 m_p c^2/hbar.
Triton = exposed trefoil remnant; a FREE open strand costs E=sigma*L -> infinity,
so every triton must re-close (be bound). f_t = n_t/(n_d+n_t) is the strain.

  nuclide  f_t(%)   regime
  C -12     0.0   deuteron-dominated (stable)
  Fe-56    16.7   iron equilibrium (peak binding)
  Sn-120   41.7   triton-loaded (strained)
  Au-197   50.6   triton-OVERLOAD -> alpha shed (He-5 ejection)
  Pb-208   55.0   triton-OVERLOAD -> alpha shed (He-5 ejection)
  Th-232   59.1   triton-OVERLOAD -> alpha shed (He-5 ejection)
  U -238   60.0   triton-OVERLOAD -> alpha shed (He-5 ejection)

  -> overload threshold ~ equilibrium f_t (~17%); beyond it a triton recruits
     an adjacent deuteron to re-form an alpha, which is shed (alpha decay).
