`zk² = 1` (k = c/v = 1/√z) is the exchange law:

| account | definition | meaning |

| rest | z = 1 | full internal budget (Law V: v_circ² + v² = c²) |
| translation | z_t = v²/c² | budget share spent moving |
| depth | z_d = ϟ_parent/r | budget share surrendered to the parent's convergence |
| rotation | z_rot = (2πR_body/T_spin)²/c² | budget share spent turning |

barycentre and `ϟ_derived(from dependent X) = ϟ_parent + ϟ_X-system`. Shadows are **row-local
additive** (H-LOCAL, the ledger's claim): each dependent's row reads the clean parent plus
**its own** system shadow — never a stranger's.
