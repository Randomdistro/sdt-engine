# Root `zk2_*.exe` runs — 2026-10-05

The 18 `zk2_*.exe` files in the repository root (untracked; `.gitignore` has `*.exe`) were each run once from a scratch folder with stdin closed and a 90 s timeout. Outputs are the `*.out.txt` files here.

- All 18 are self-contained: none opens a data file, and none created or modified any file. Data tables are hard-coded in the sources (`Hubble/tools/zk2_*.cpp`) and printed.
- 17 of 18 outputs are identical (trailing whitespace ignored) to the output of a fresh build of the current source (MSVC 19.44, `/O2`). `zk2_mapper` prints its usage text and exits 1 because it needs arguments (`star`, `orbit` or `system`).
- `zk2_m31`: the old exe (`zk2_m31.exe`, 6 April) ran normally (71 lines). A fresh build of `zk2_m31_stars.cpp` and a copy of it were detected by Microsoft Defender as `Trojan:Win64/Injector.NA!MTB` (a machine-learning-class detection) at 10:44:45 and 10:45:32 on 2026-10-05, and Defender removed both (`Get-MpThreatDetection`: action succeeded, threat inactive). No comparison with the old exe was possible. The detection log names only those two scratch files; none of the other rebuilt binaries, none of the 18 original root exes and none of the scratch copies of them was reported.
- Checks after the detection (2026-10-05): the source `zk2_m31_stars.cpp` (254 lines) includes only iostream, cmath, string, vector, sstream, iomanip and algorithm and contains no process, memory, network or shell calls (grep for VirtualAlloc, WriteProcessMemory, CreateRemoteThread, LoadLibrary, system(), CreateProcess, sockets, inline asm: no hits). Defender custom scans of the original `zk2_m31.exe` (sha256 prefix 41a061b49bc1809b) and of both scratch folders completed with no new detection. A scan that reports nothing is not proof, and the `!MTB` class is heuristic, so a false positive on a freshly compiled unsigned binary is possible but not established. The 17 other original exes were executed before the detection and nothing was flagged at run time.
- Name mapping exe → source: allp → all_planets, amptest → amplitude_test, candle → candle_normaliser, epseri → epsilon_eridani, jovint → jovian_integers, jscan → jov_scan, m31 → m31_stars, mapper → system_mapper, spation → spation_profile, spation_deep and spdeep → spation_deep (both give identical output), syscmp → system_compare. `zk2_dark_investigation` and `zk2_flyby_anomaly` have sources but no `zk2_` exe in the root (a `flyby_anomaly.exe` exists there).
