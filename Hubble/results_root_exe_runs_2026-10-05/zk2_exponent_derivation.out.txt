## 4. Dimensional Constraint Argument

### 4.1 Why Sum = d_eff

```
In a d-dimensional lattice, a wavelength decouples from
the pressure gradient at a surface of dimension d_surface.

The decoupling condition is:
  opacity(lambda, r) = tau_critical

The opacity profile divides into two regimes about lambda_0.
The total 'angular phase space' covered by both regimes must
equal the surface dimensionality:

  p_short + p_long = d_surface

For 3D space with spherical decoupling surface: d_surface = 2
Measured: 1.9896 vs predicted: 2.0000
```

### 4.2 Why delta = 1/(d_surface + d_bulk - 1) = 1/4

```
The asymmetry between short-side and long-side coupling:

  Short side: lambda < lambda_0 → resonance coupling
    Each oscillation cycle fits inside the lattice spacing
    → energy leaks per cycle → steeper decoupling
    → p = 1 + delta

  Long side: lambda > lambda_0 → impedance mismatch
    Oscillation exceeds lattice coherence length
    → coupling weakens continuously → shallower decoupling
    → p = 1 - delta

The splitting parameter delta from mode partition:
  delta = 1 / (d_surface + d_bulk - 1)
        = 1 / (2 + 3 - 1) = 1/4 = 0.2500

Measured: 0.2396
CAVEAT: This is a CONSTRAINT argument, not a first-principles
derivation. A rigorous derivation would require computing
the mode-coupling coefficient from the lattice Hamiltonian.
```

## 7. Verdict

```
Question: Are the exponents (5/4, 3/4) predicted or fitted?

Answer: PARTIALLY CONSTRAINED.

  1. The SUM = 2 constraint is dimensionally motivated
     and the data satisfy it to 0.52%. STRONG.

  2. The SPLITTING delta = 1/4 is a mode-partition argument
     that fits the data to 4.17%. REASONABLE.

  3. The AMPLITUDES (A_s, A_l) are still fitted from data.
     They are not predicted from first principles.

  4. Individual band predictions using theoretical exponents
     deviate from measurement by up to several percent
     for coronal bands (hard X, Fe lines), because the
     corona is NOT a simple opacity-decoupling surface.

STATUS: The exponents are CONSTRAINED by dimensional
arguments, not derived from lattice dynamics. A full
derivation requires the lattice Hamiltonian and
mode-coupling computation, which does not yet exist.
```
