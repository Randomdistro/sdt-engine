## 1. The Ratio Signature

```
Observation: spectral lines in distant objects are
shifted by the SAME multiplicative factor (1+z).

  Si II 635.5 nm  →  635.5 × (1+z) nm
  Ca II 396.8 nm  →  396.8 × (1+z) nm
  H-α   656.3 nm  →  656.3 × (1+z) nm

This is a RATIO, not an additive shift.
A ratio emerges from multiplicative compounding:

  Each lattice element dl multiplies λ by (1 + κ dl)
  Over distance d: λ_obs/λ_emit = Π(1 + κ dl) = exp(κd)
  Therefore: 1 + z = exp(κ₀ d)
             d = ln(1+z) / κ₀

An additive mechanism (metric stretching) would give:
  δλ = constant for all λ  →  z = δλ/λ varies by line
  This is NOT observed.
```

```

   F = L/(4πd²) × 1/(1+z)²
   Both energy loss and arrival-rate dilation.
   d_eff = d × (1+z)
```
